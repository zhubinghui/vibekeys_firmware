# UI Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 统一全 UI 到中文字体、背景图改为 2s 开机画面、并落地已批准的 P0/P1/P2 屏幕改造清单（密码轮符号组、WiFi 失败重试、OTA 进度、开机菜单底栏、键盘主屏状态栏、会话列表状态前缀、弹窗三色、终端回滚指示）。

**Architecture:** 全部改动落在既有四个文件（ui.rs / main.rs / lcd.rs / ota.rs / app.rs），不新增模块。字体统一 = ui.rs `draw_text` 委托 wqy16 路径后删除 ASCII 专用路径；开机画面复用 `lcd::display_png`（其 `fix_background + sleep(timeout)` 语义即所需）；OTA 进度用独立 `mpsc` 通道从 worker 回传主线程绘制。UI 绘制代码无宿主测试哈内斯，每个任务以 `vkbuild max2` 编译通过为门槛，末尾全变体构建 + 真机烟测清单。

**Tech Stack:** Rust (esp toolchain, Xtensa) · embedded-graphics + embedded-text + u8g2_fonts(wqy16/unifont) · ESP-IDF via esp-idf-svc。构建：`vkbuild keys` / `vkbuild max2`（zsh 函数；非交互 shell 需手动 `PATH="/opt/homebrew/opt/python@3.12/libexec/bin:$PATH" ./build.sh max2` 且先 `source ~/export-esp.sh`）。

**Spec:** 本对话批准的清单 + 模拟图 artifact（claude.ai/code/artifact/227e7d59-80b6-48a9-97c5-4005793fca27）。要点：
1. 字体统一：ui.rs 所有文本走 wqy16（终端流保留 unifont 栈不动）。
2. 开机画面：上电后若 NVS 有 background_png → `display_png` 显示 2s；键盘/Remote 模式不再绘制常驻背景。
3. P0·1 密码轮：abc/ABC/123/#!? 四组（NEXT 切组）、轮盘末尾 OK 格提交、ESC=取消不保存。
4. P0·3 Remote WiFi 连接失败：红框弹窗 ACCEPT=重试 / ESC=重启回菜单（替代 sleep 60s 强制重启）。
5. P0·4 OTA：下载/上传进度条 + 字节数/百分比 + "do not power off"。
6. P1·5 开机菜单：底部摘要行（wifi 数 + server host）+ 键位提示栏（仅屏高 ≥150px 绘制）。
7. P1·6+7 键盘主屏：16px 四槽状态栏（WiFi/BLE·n/MQTT/ASR + 右侧版本号）、信息行（SSID/ASR 路径/MIC 模式）、入场一次性 "ESC+ACCEPT = menu" 提示。
8. P1·8 会话列表：●/○ 前缀、焦点底色统一 CSS_DARK_CYAN、标题 n/m 计数、右缘滚动条（render_list 同加）。
9. P2·9 弹窗三色：黄=进行中（loading/connecting/recording 起始）、绿=就绪（listening/recording）、红=错误（MQTT disconnected / ASR error / WiFi failed）。
10. P2·10 终端回滚指示：JPEG 与 text 模式滚离底部时右上角橙色 `^ n` 角标，回底消失。

## Global Constraints

- 屏幕：max2 = 320×172，keys = 284×78。所有 y ≥ 90 的新元素必须以 `height` 计算并在矮屏跳过（`if height >= 150`）。
- `LINE_H = 18` 不变；wqy16 具备 GB2312 覆盖，缺字静默跳过（u8g2 默认），不 panic。
- 模式退出 = 重启（既有设计），新增模态循环不需处理 ExitChord（全部改动位于 boot/Setting 阶段或既有循环内）。
- 固件颜色只用 `ColorFormat::CSS_*` 常量。
- 每任务完成后 `vkbuild max2` 必须编译通过（增量 ~15s）；最终两变体都过。
- 提交信息用 conventional commits（feat/fix/refactor + 中文摘要，与仓库近期风格一致）。

```rust
SettingState::PassEditor => {
    let group = CHARSET_GROUPS[cur_group];
    let wheel_len = group.len() + 1; // 末位 = OK
    let _ = render_password(target, &pending_ssid, &password, cur_group, cur_char);
    match wait_input(rot_a, accept, esc, next, backspace).await {
        InputEvt::Next => {
            cur_group = (cur_group + 1) % CHARSET_GROUPS.len();
            cur_char = 0;
        }
        InputEvt::Rotate => {
            cur_char = rotate_index(cur_char, wheel_len, rot_down(rot_a, rot_b));
        }
        InputEvt::Accept => {
            if cur_char == group.len() {
                // OK:提交(沿用原 Esc 分支的保存逻辑)
                match cur_editing {
                    Some(i) if i < setting.wifi_list.len() => {
                        setting.wifi_list[i].ssid = pending_ssid.clone();
                        setting.wifi_list[i].pass = password.clone();
                    }
                    _ if setting.wifi_list.len() < MAX_WIFI_CREDS => {
                        setting.wifi_list.push(WifiCred {
                            ssid: pending_ssid.clone(),
                            pass: password.clone(),
                        });
                    }
                    _ => {}
                }
                if let Err(e) = BtSetting::save_wifi_list(nvs, &setting.wifi_list) {
                    log::error!("Failed to save wifi_list: {:?}", e);
                }
                cred_focus = cur_editing.unwrap_or(setting.wifi_list.len().saturating_sub(1));
                cur_editing = None;
                pending_ssid.clear();
                password.clear();
                cur_char = 0;
                state = SettingState::WifiCreds;
            } else if password.len() < 32 {
                password.push(group[cur_char] as char);
            }
        }
        InputEvt::Backspace => {
            password.pop();
        }
        InputEvt::Esc => {
            // 取消:丢弃本次编辑,不落盘。
            cur_editing = None;
            pending_ssid.clear();
            password.clear();
            cur_char = 0;
            state = SettingState::WifiCreds;
        }
    }
}

/// 右缘滚动条:total > visible 时画 3px 轨道 + 按比例的青色滑块。
fn draw_scrollbar(
    target: &mut FrameBuffer,
    top: i32,
    total: usize,
    start: usize,
    visible: usize,
) -> anyhow::Result<()> {
    if total <= visible {
        return Ok(());
    }
    let bb = target.bounding_box();
    let x = bb.size.width as i32 - 3;
    let h = bb.size.height as i32 - top;
    fill_rect(
        target,
        Rectangle::new(Point::new(x, top), Size::new(3, h as u32)),
        ColorFormat::CSS_DARK_SLATE_GRAY,
    )?;
    let thumb_h = ((h as usize * visible / total).max(8)) as u32;
    let max_start = total - visible;
    let thumb_y = top + (h - thumb_h as i32) * (start.min(max_start) as i32) / max_start as i32;
    fill_rect(
        target,
        Rectangle::new(Point::new(x, thumb_y), Size::new(3, thumb_h)),
        ColorFormat::CSS_DARK_CYAN,
    )
}
```

const STATUS2_H: u32 = 16;

pub fn render_keyboard_home(target: &mut FrameBuffer, h: &KeyboardHome) -> anyhow::Result<()> {
    let bb = target.bounding_box();
    let (width, height) = (bb.size.width, bb.size.height);
    target.restore_background();
    // 16px 四槽状态栏
    fill_rect(
        target,
        Rectangle::new(Point::new(0, 0), Size::new(width, STATUS2_H)),
        ColorFormat::CSS_DARK_SLATE_GRAY,
    )?;
    let slot = |on: Option<bool>| match on {
        Some(true) => ColorFormat::CSS_GREEN,
        Some(false) => ColorFormat::CSS_RED,
        None => ColorFormat::CSS_GRAY,
    };
    let ble_text = format!("BLE:{}", h.ble_conns);
    let slots: [(&str, ColorFormat); 4] = [
        ("WiFi", slot(Some(h.wifi_on))),
        (&ble_text, if h.ble_conns > 0 { ColorFormat::CSS_BLUE } else { ColorFormat::CSS_GRAY }),
        ("MQTT", slot(None)), // 键盘模式无 MQTT
        ("ASR", slot(Some(h.asr_on))),
    ];
    let mut x: i32 = 4;
    for (label, dot) in slots {
        fill_rect(target, Rectangle::new(Point::new(x, 5), Size::new(6, 6)), dot)?;
        let lw = (label.len() as u32) * 8 + 4;
        draw_text(
            target,
            label,
            Rectangle::new(Point::new(x + 8, -1), Size::new(lw, STATUS2_H)),
            ColorFormat::CSS_WHITE,
            None,
            HorizontalAlignment::Left,
        )?;
        x += 8 + lw as i32 + 6;
    }
    draw_text(
        target,
        concat!("v", env!("CARGO_PKG_VERSION")),
        Rectangle::new(Point::new(width as i32 - 56, -1), Size::new(52, STATUS2_H)),
        ColorFormat::CSS_GRAY,
        None,
        HorizontalAlignment::Right,
    )?;
    // 居中标识
    let mid = Rectangle::new(
        Point::new(0, (height / 2 - LINE_H) as i32),
        Size::new(width, LINE_H * 2 + 4),
    );
    draw_text(
        target,
        &format!("Keyboard\n{}", h.ble_mac),
        mid,

            crate::lcd::display_text(target, "OTA failed\n ESC to back", 0)?;

            wait_button_release(accept_btn);
            crate::lcd::display_text(target, "OTA Mode\n Requesting latest...", 0)?;
            let _ = screen_tx.send(OtaEvent::DownloadLatest);

/// 右上角回滚角标:黑底橙框橙字 `^ n`。返回角标 rect(调用方负责 flush_rect)。
pub fn draw_scroll_badge(target: &mut FrameBuffer, n: usize) -> anyhow::Result<Rectangle> {
    let bb = target.bounding_box();
    let text = format!("^ {n}");
    let w = (text.len() as u32) * 8 + 10;
    let rect = Rectangle::new(Point::new(bb.size.width as i32 - w as i32 - 4, 2), Size::new(w, 20));
    fill_rect(target, rect, ColorFormat::CSS_BLACK)?;
    rect.draw_styled(
        &PrimitiveStyle::with_stroke(ColorFormat::CSS_DARK_ORANGE, 1),
        target,
    )?;
    draw_text(
        target,
        &text,
        Rectangle::new(
            Point::new(rect.top_left.x + 4, rect.top_left.y),
            Size::new(w - 8, 20),
        ),
        ColorFormat::CSS_DARK_ORANGE,
        None,
        HorizontalAlignment::Left,
    )?;
    Ok(rect)
}

```rust
/// 文本终端回滚角标:不在内容底部时显示 `^ 行数`,回底后重画窗口清除。
fn update_scroll_badge(&mut self) -> anyhow::Result<()> {
    if self.terminal_parser.is_none() {
        return Ok(());
    }
    let bottom = self.terminal_content_bottom_offset();
    let rows_up = bottom.saturating_sub(self.terminal_offset);
    if rows_up > 0 {
        let rect = crate::ui::draw_scroll_badge(&mut self.display, rows_up as usize)?;
        self.display.flush_rect(rect)?;
        self.scroll_badge_shown = true;
    } else if self.scroll_badge_shown {
        if let Some(rect) = self.render_terminal_window_diff(true)? {
            self.display.flush_rect(rect)?;
        }
        self.scroll_badge_shown = false;
    }
    Ok(())
}
```
